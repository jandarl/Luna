Project Luna is a Inventory and cart checkout system that has a user control for two types of log-in ( Administrator and User ).

The administrator can view and manage the inventory. Adding item stock with their type, price and the stock availability in the area and more in the future will be part of the item information.

The user ( usually a cashier ) can add items to cart while displaying the price and item count in stock while also displaying the total price of the added items in the cart.
Once the checkout button event is fired, the items will be deducted from the stock. 

This system uses React and React Bootstrap for the front end ( NearSide ) and will use ExpressJS for the back end ( FarSide ). For this project I have used the PostgreSQL for the database.

This is a work in progress or may be totally re-invented as I and the requestor of this system has currently gone back to the drawing board because there is a big change of the requirement.
